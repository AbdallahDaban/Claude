Add it to your email

  1. Gmail: Settings → See all settings → Signature → Create new → paste.
  2. Outlook (web and new Outlook): Settings → Mail → Compose and reply → Email signature → paste.
  3. Outlook for Windows (classic): tick "I use Outlook for Windows" first. Then File → Options → Mail → Signatures → New → paste.
  4. Apple Mail: Settings → Signatures → + → paste, then untick "Always match my default message font".
The banner must be hosted on the web, because email apps block local images. Upload the four GIFs in this folder to the address above (for example https://fleetana.sa/email/) once, and every signature will use them. Classic Outlook for Windows shows only the first frame of a GIF, so its version starts on the finished logo.
