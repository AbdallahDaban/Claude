# Claude — Motion Reel '26

A 15-second, 1080p60 motion-graphics showreel. Every frame is generated by code: no keyframes, no footage, no samples.

- `reel.html`: the animation engine. Every frame is a pure function of time (`render(frame)`), so frames can render in any order. Open it in a browser and click to play it with sound.
- `render.mjs`: headless export. It renders the 900 frames on 4 parallel Chromium pages and pipes them into ffmpeg/x264.
- `score.py`: the original soundtrack (120 BPM), synthesized with numpy. Hits are placed on the same timeline as the visual cuts.
- `showreel.mp4`: the final render.

| Time | Section | Technique |
|---|---|---|
| 0–2s | Ident | overshoot dot, shockwave rings, trim-path bursts, masked letter rise, slice exit, skewed wipe |
| 2–4s | Kinetic type | "Every frame is a decision", one treatment per word, outline stack, iris transition |
| 4–6s | Geometry | 3D torus knot morphs into a sphere, depth-coded strokes, annotation callouts |
| 6–8s | Particles | 5,600 particles burst from the sphere into "CRAFT", then a ripple, then collapse onto the grid |
| 8–10s | Systems | 144-tile Bauhaus grid driven by travelling waves, scramble type, implosion |
| 10–12s | Principles | the drop: tunnel and serif statements (timing, spacing, weight, feel) |
| 12–13.5s | Montage | halftone, squash & stretch, isometric, signal, orbitals, glitch |
| 13.5–15s | End card | spark mark, wordmark, role |

Rebuild: `python3 score.py showreel.wav && node render.mjs showreel.mp4 showreel.wav`
